## 关键算法细节

### 稳健链接 (Robust Chaining)
解析器基于 **2D 几何邻近性** ($10^{-10}$ 容差) 构建边图，而不是仅依赖 3D 拓扑连接。这有效处理了 3D 顶点合并但 UV 点分离（缝合边）的情况。

### 绕数逻辑 (Winding Number logic)
```cpp
// 对于每个环 A，我们要找到“最佳父节点” B
// 方法是检查 WindingNumber(PointOnA, B) != 0。
// “最佳父节点”是指包含 A 且面积最小的那个环。
```
这确保了即使存在“岛中有孔，孔中又有岛”的情况，层级关系也能被正确重建。
