# BRepAlgo_Loop 重构工作指南 (Walkthrough)

我已完成了对 [BRepAlgo_Loop](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.hxx#36-37) 的全阶段重构。此次重构旨在提升 API 的易用性、增强错误诊断能力，并通过高性能的空间聚类算法大幅提升核心逻辑速度。

## 核心变更内容

### 1. 现代化流畅 API: [BRepAlgo_LoopBuilder](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_LoopBuilder.cxx#18-23)

引入了符合现代 C++ 习惯的“构建者模式” API。

- **易用性**: 支持链式调用，减少了遗留接口中繁琐的初始化步骤。
- **模糊闭合检查 (Fuzzy Closure Check)**：针对偏移算法（Offset）中常见的 UV 空间微小间隙，增加了自动提升顶点容差并尝试重新闭合的逻辑。这是解决 `bug5805_1` 等用例中面缺失问题的关键。
- **拓扑一致性维护**：集成了 `myVerticesForSubstitute` 的全局更新，确保跨面拼接时的顶点一致性。
- **编译修复**：修复了在 Windows 环境下使用 `NCollection_DataMap` 迭代器进行赋值时导致的 C2678 编译错误。
- **隐式状态管理**: 内部自动管理 `BRepAlgo_Image` 和顶点替换图。

### 2. 结构化结果与诊断: [BRepAlgo_LoopBuildResult](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_LoopBuildResult.hxx#25-27)

新的 [Build()](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_LoopBuilder.cxx#81-119) 方法不再只是返回一个 `TopAbs_Shape`，而是返回一个包含丰富信息的结构化对象：

- **执行状态**: 包括 [Success](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_LoopBuildResult.hxx#31-33)（成功）、`PartialSuccess`（部分成功）、`Failed_OpenLoop`（开环失败）等。
- **详细诊断**: 能够直接获取“问题形状”（Problematic Shapes），方便用户在构建失败时快速定位是不闭合的边还是错误的顶点。

### 3. 高性能顶点聚类: [Toolkit_VertexClusterer](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/Toolkit_VertexClusterer.cxx#66-71) (核心提升)

这是本次重构在性能方面的重大改进。

- **空间索引**: 使用 [NCollection_CellFilter](file:///d:/VS/OCCT-8.0-refactor/src/FoundationClasses/TKernel/NCollection/NCollection_CellFilter.hxx#139-147)（网格过滤）技术。
- **复杂度优化**: 将顶点匹配的复杂度从原有的 $O(N^2)$ 降低到了平均 $O(N \log N)$。对于包含数千个连接点的复杂模型，处理速度提升显著。

### 4. 健壮的新算法: [PerformNew](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.cxx#554-731)

在 [BRepAlgo_Loop](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.hxx#36-37) 内部实现了一个全新的逻辑路径。它利用 [Toolkit_VertexClusterer](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/Toolkit_VertexClusterer.cxx#66-71) 预先构建清晰的拓扑连接图，比旧版逻辑更能容忍细微的公差误差。

## 使用示例与迁移

### 旧接口 (不推荐)

```cpp
BRepAlgo_Loop loop;
loop.Init(face);
loop.AddConstEdges(edgeList);
loop.Perform(); // 旧逻辑复杂度高，且出错时难以诊断
const TopTools_ListOfShape& wires = loop.NewWires();
```

### 新接口 (推荐)

```cpp
// 推荐的现代化写法
BRepAlgo_LoopBuildResult result = BRepAlgo_LoopBuilder(edgeList)
                                    .Init(face)
                                    .SetTolerance(1e-3)
                                    .Build();

if (result.IsSuccess()) {
  const TopTools_ListOfShape& wires = result.Wires();
} else {
  // 快速分析未闭合的边
  const TopTools_ListOfShape& brokenWires = result.ProblematicShapes();
}
```
