已完全重写 extractUVLoops，实施了 **几何组装器 (Geometric Assembler)** 方案。
新逻辑特点：
1. 抛弃拓扑依赖：不再使用MapShapesAndAncestors，彻底解决“拓扑断开但几何重合”的 Edge Soup 问题。
2. 贪婪几何搜索：
    - 将所有边（及其反向副本）展平成候选列表。
    - 从当前端点出发，遍历所有候选边，计算 UV 距离（含周期性偏移）。
    - 选取**距离最小**且小于容差（1.0）的边作为下一条。
3. 自动展开 (Unrolling)：
    - 在连接时记录周期性位移（Shift）。
    - 在离散化成 Polygon 时，累加位移，生成连续的 2D 多边形，确保 Winding Number 计算正确。
现在系统应该能像拼图一样，自动把那些乱序、有缝隙的 Offset Edges 拼成闭合回路。
