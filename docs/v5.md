## 核心变更

### 1. 稳健的选边策略 ([SelectEdge](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.cxx#335-1170))

这是本次重构最关键的改进，解决了 Loop 构建中“下一条边选谁”的核心难题：

- **问题**: 原有逻辑完全依赖 2D UV pcurve 的距离和方向。在遇到 UV 不连续区域（如闭合面的缝合线、球体极点，典型用例 `C3`）时，2D 距离检查会失效（距离远超容差），导致算法随机“盲选”或选错方向。
- **解决方案**:
  - **2D/3D 混合距离检查**: 算法现在优先检查 2D UV 距离。如果 2D 检查不通过（pcurve 不连续），会自动无缝降级到 **3D 顶点距离** 检查，确保只要物理上连通，拓扑就不会断裂。
  - **3D 切向评分**: 选边评分不再依赖不稳定的 2D 方向，而是统一计算 **3D 切向量** 的点积（Dot Product）。这确保了即使在 UV 坐标系完全混乱的地方，算法依然能根据 3D 几何形状选出“最直”或“转弯最自然”的下一条边。
- **成果**: 彻底修复了 `C3`（负体积/导向错误）、`B2`（Wire 无法闭合）等疑难杂症，并显著提升了 `F2` 的处理能力。

### 2. API 调用安全性 ([PerformNew](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.hxx#92-94))

- **修复**: 调整了在 `BRep_Builder` 中删除边的操作顺序。现在会确保在调用 [Remove](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.cxx#220-283) 之前先获取必要参数，避免触发 `Standard_NoSuchObject` 异常（修复了 `M6` 的运行时崩溃）。

### 3. 拓扑一致性 ([UpdateVEmap](file:///d:/VS/OCCT-8.0-refactor/src/ModelingAlgorithms/TKBool/BRepAlgo/BRepAlgo_Loop.cxx#1016-1170))

- **修复**: 重写了顶点-边映射（VE map）的去重逻辑。现在能正确区分“几何重合”但“逻辑不同”的顶点（如缝合线两侧的顶点），防止错误的顶点合并导致 Wire 拓扑混乱。
